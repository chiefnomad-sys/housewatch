# Housewatch

News site and newsletter (Housewatch Daily) for the everyday firefighter. Astro, with Keystatic for editing, deployed on Netlify at housewatch.news. homewatch.news and the www names redirect there (see `netlify.toml`).

```
npm install
npm run dev      # http://localhost:4321, editor at /keystatic
npm run build    # output in dist/
```

## Where things live

- `src/content/articles/*.md`: stories. Front matter: title, dek, date, beats (first is the main beat), short (The short version lines), sources, corrections, featured, draft.
- `src/content/pages/*.md`: About, Corrections policy, Contact and Privacy text.
- `src/site.ts`: name, tagline, beats, and `look` ('white' or 'black') which flips the whole site's background.
- `src/data/marks.ts`: the engine house wordmark and the gothic H, generated by `tools/make_marks.py` from the logo set.
- `src/cards/render.ts`: builds the share cards (`/cards/<story>.png`, 4:5) and link previews (`/og/<story>.png`) at build time. Cards are text only, never photos.

## Adding a story

Write it in Keystatic (`/keystatic`, Stories > Add), or drop a Markdown file in `src/content/articles/`. The homepage, beat pages, RSS, cards and previews all update on the next build. The newest story leads the homepage unless one is ticked Lead story.

## Housewatch Daily signup and the contact form

Both use Netlify Forms. In Netlify, turn on form detection (Forms > Enable form detection) once, then redeploy. Signups show under Forms > daily. Swap in a newsletter provider later by changing the form in `src/components/Daily.astro`.

## Keystatic on the live site

Same one-time GitHub app setup as Vertical Brief: run `PUBLIC_KEYSTATIC_STORAGE=github npm run dev`, create the GitHub app at /keystatic for the `chiefnomad-sys/housewatch` repo, add the callback URL `https://housewatch.news/api/keystatic/github/oauth/callback`, then add the four values from `.env` to Netlify's environment variables. Never commit `.env`.
